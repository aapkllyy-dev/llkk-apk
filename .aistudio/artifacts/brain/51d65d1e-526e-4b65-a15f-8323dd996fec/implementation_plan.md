# 跨端落地与正式投产方案 (Mobile & Desktop Dual-Screen Production Readiness Plan)

全面落地多店共享客资、出入账流水录入、各银行卡与群业绩对账、选项增删改及手机/电脑双端自适应交互体系，确保各门店与线上客服团队随时开机即用。

---

## User Review & Critical Decisions

> [!IMPORTANT]
> **关键决策与落地确认项**
> - **手机与电脑双端自适应 (Dual-Screen Ergonomics)**：移动端采用拇指友好的大触控按键、底部安全操作区与防误触卡片；电脑端（宽度 ≥ 1024px）采用自适应高信息密度排版与快速键盘 Tab 连录。
> - **经手员工姓名追踪与本机自动记忆 (Staff Accountability & Auto-Remember)**：每笔流水必须记录经手员工姓名（录单人）；每台手机或电脑记住当前值班员工，下笔入账无需重复输入；流水卡片与总账清晰标明记录人，问责清晰绝不找错人；支持员工名单的增删改。
> - **去除冗余顾客姓名，以游戏 ID 为核心识别**：应用户要求移除繁琐的顾客姓名输入，只保留顾客【游戏 ID (账号)】作为核心标识，老客自动识别并累加充值/洗分次数。
> - **实时多店云端数据一致性**：通过轻量级高频心跳保持数据多端秒级同步，支持断网重连保护与空状态容错。
> - **测试数据处理机制**：已在系统设置中设置了“正式启用准备（清空测试流水）”隔离按钮，一键清空测试数据的同时，100% 完整保留老板自定义配置的群、银行账户、分店名及快捷金额。

## 1. Overview & Core Concept

- **What It Does (系统定位)**：专为游戏厅、多门市与线上客服运营定制的无缝跨端流水与财务对账管理软件。
  1. **日常流水极速录入 (Staff View)**：录入进分 (Bank-in) 与洗分 (Cuci)，自动识别老客户，自动累加第几次充值/洗分。
  2. **财务与老板总账核算 (Ledger View)**：日账、周账、月账与自定义查账一键切换；银行卡进出明细与群业绩全自动计算；支持一键复制微信/WhatsApp对账报表及一键导出 Excel。
  3. **自由度 100% 选项管理 (Settings View)**：在界面中随时增、改、删 WhatsApp 群、银行账户、门店与快捷金额，且支持跨历史账目批量更名。
- **Target Audience (目标人群)**：各分店前台员工、线上值班客服、门店经理与财务老板。
- **Core Value (核心价值)**：彻底杜绝人工算错账、漏记客户充值次数、网银与账本对不上等传统痛点，零培训成本，手机电脑即开即用。

### 2.2 视觉与色彩系统 (Color & Typographic Tokens)
- **Neutral Background (60%)**：深冷暗石墨色 (`bg-slate-950` / `#020617`)，降低夜班盯屏视觉疲劳。
- **Structural Surfaces (30%)**：精细卡片表面 (`bg-slate-900`、`border-slate-800`)，单层轻量阴影。
- **Semantic Accents (10%)**：
  - **进分 / 充值 / 收益**：翡翠绿 (`text-emerald-400` / `bg-emerald-500` / `border-emerald-500/40`)
  - **洗分 / 出款 / 扣减**：玫瑰红 (`text-rose-400` / `bg-rose-500` / `border-rose-500/40`)
  - **总账 / 警告 / 强调**：琥珀金 (`text-amber-300` / `bg-amber-400` / `border-amber-500/40`)
  - **银行 / 凭据**：靓靛蓝 (`text-indigo-400`)
- **排版规范**：
  - 核心金额与笔数：强制使用 `tabular-nums` 与 `font-mono`，确保大数字在手机与电脑屏幕上横向对齐不跳动。
  - 按钮与标签：全部单行呈现 (`whitespace-nowrap`)，触摸有效面积 ≥ 44×44px。

## 3. Key Product Decisions & Implementation Tasks

### 任务 1：双端交互与触摸体验深度落地 (Mobile & Desktop Dual-Screen Polish)
- **优化点**：
  - 针对手机端竖屏视图，将表单输入框的数字键盘触发优化（`inputMode="decimal"`），输入金额时手机自动弹出全数字键盘。
  - 在移动端顶部紧凑折叠分店选择与说明按钮，保持第一屏净高度，防止软键盘弹起时遮挡提交按键。
  - 电脑端优化大屏两栏/自适应网格，使财务人员单手敲回车即可快速录完一单。

### 任务 2：离线容错与轻量网络心跳 (Real-Time Sync & Resilience)
- **优化点**：
  - 优化 `fetchData` 3 秒心跳：当移动设备因切换应用或锁屏短暂断网时，不弹出突兀的报错弹窗，并在网络恢复后 0.5 秒内自动静默同步。
  - 数据提交添加防止“双击重复提交”防抖保护（`isSubmitting` 锁定按钮并显示保存中动画）。

### 任务 3：落地准备与系统初始化校验 (Production Launch Verification)
- **优化点**：
  - 检查所有预设项（WhatsApp 5个默认群、常见银行、门店、快捷金额）与 `data/db.json` 持久化文件的读写一致性。
  - 确保“一键清空测试记录”功能在正式启用时能稳定将历史流水重置为 0，同时完全锁定群与银行等基础配置不被误删。

## 5. Verification Plan

1. **双端界面自适应验证 (Mobile & Desktop Viewports)**：
   - 验证移动端（375px–430px）竖屏各按钮触控面积 ≥ 44px，无水平溢出，数字键盘弹出顺畅。
   - 验证电脑端（1024px–1440px）大屏布局饱满，表格清晰，横向对账舒适。
2. **功能闭环验证 (End-to-End Handlers)**：
   - 验证录单、客户自动次数识别、单笔修改、微信/WhatsApp对账单复制。
   - 验证选项管理（加群、改银行名、改快捷金额、批量更名客户）。
   - 验证清空测试数据与开启正式运营。
3. **构建与代码质量检查**：
   - 运行 `compile_applet` 和 `lint_applet` 确保 TypeScript 零错误、零语法告警。
